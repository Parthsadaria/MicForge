# Micforge v1.1.0 Release Notes

**Release Date:** November 2026  
**Status:** Production Grade • Ultra-Low Latency • Neural & Classical Hybrid  

Micforge v1.1.0 is a major milestone release. This update brings neural speech enhancement powered by **CoFi-Lite**, slashes end-to-end audio latency from over 120 ms to **under 70 ms**, completely eliminates startup buffer glitches (0 glitches), and introduces full Windows background daemon capabilities including a **System Tray icon**, **System-wide Global Hotkeys**, **Isolated Audio Chimes**, and an interactive **Settings GUI**.

---

## 🚀 Key Highlights & New Features

### 1. 🧠 CoFi-Lite Neural Speech Enhancement
- **Deep Learning Voice Cleaning:** Integrated the CoFi-Lite neural speech model for studio-grade noise suppression, removing complex non-stationary noises (mechanical keyboards, room echo, fans, street traffic) while preserving natural voice warmth.
- **ONNX Runtime Acceleration:** Optimized for real-time CPU execution using ONNX Runtime with float32 SIMD vectorization. Extremely lightweight footprint (<100 MB RAM, single-digit % CPU usage).
- **Model Switcher CLI & Tools:**
  - `micforge model info` — Inspect input/output shapes, sample rates, and parameter counts.
  - `micforge model export <checkpoint> <output.onnx>` — One-command conversion tool with dynamic checkpoint loading.
- **Instant Hot-Swapping:** Switch on the fly between **CoFi-Lite Neural** (high quality, ~67 ms) and **Classical Spectral Wiener** (ultra-fast, ~47 ms) directly from the CLI or system tray.

---

### 2. ⚡ Latency Reduction (< 70 ms)
- **Cut Latency in Half:** Slashed end-to-end audio roundtrip latency from **~123 ms** down to **67.6 ms** with CoFi-Lite, and **47.6 ms** with Spectral Wiener.
- **STFT Group Delay Optimization:** Re-evaluated causal lookahead parameters, reducing algorithmic delay from 2,335 samples (48.6 ms) down to 1,470 samples (30.6 ms).
- **Jitter Buffer Streamlining:** Optimized WASAPI safety buffer cushions from 3.0 blocks down to 1.5 blocks (15 ms), delivering lightning-fast voice chat response in competitive gaming and Discord calls.
- **Accurate Throughput Telemetry:** Refined dashboard calculation to measure true operational pipeline latency rather than theoretical driver overhead.

---

### 3. 🛡️ Zero Startup Glitches & Clock Drift Correction
- **Active Sink Gating:** Output streams are now gated until the first real mic block is captured by the input stream. This eliminates the initial ~56 false underrun glitches caused by empty WASAPI buffers during startup.
- **Adaptive Ring Buffer Synchronization:** Robust moving-average clock synchronization dynamically absorbs sample rate drift between different physical hardware devices (e.g. USB mic and motherboard audio).

---

### 4. 🎛️ Windows System Tray Daemon (`--tray`)
- **Background Mode:** Run Micforge completely hidden in the background without needing a visible console window open:
  ```bash
  micforge --tray
  ```
- **Dynamic Taskbar Icon:** Procedurally rendered 64×64 icon that changes color based on your live state:
  - 🔵 **Cyan:** Active & Processing
  - ⚪ **Gray with Red Slash:** Mic Muted
  - 🟡 **Amber:** DSP Bypassed (Raw Mic)
- **Context Menu:** Right-click tray menu provides:
  - Quick Mute / Unmute
  - Bypass DSP toggle (instant A/B testing)
  - Quick Preset selector (*Discord*, *Clean*, *Noisy Room*, *Podcast*, *Broadcast*, etc.)
  - Model Switcher (*CoFi-Lite Neural* ⟷ *Spectral Wiener*)
  - "Start on Windows Boot" toggle
  - Show / Hide Console Dashboard
  - Settings & Hotkeys GUI

---

### 5. ⌨️ Global System-Wide Hotkeys
- **Works in Fullscreen Games:** Built using non-intrusive low-level Windows keyboard hooks via `pynput`. Hotkeys trigger even while inside fullscreen games and applications:
  - `Ctrl + Shift + M`: Toggle Mute
  - `Ctrl + Shift + B`: Toggle DSP Bypass
  - Push-to-Talk (PTT) & Push-to-Mute (PTM) modes supported.
- **Customizable:** Fully rebindable to any key combination.

---

### 6. 🔔 Isolated Headphone Audio Cues (Chimes)
- **Real-Time Audio Feedback:** Never speak on mute by accident again:
  - **Blip** (Descending chime: 460 Hz → 280 Hz): Muted
  - **Chirp** (Ascending chime: 280 Hz → 540 Hz): Unmuted
  - **Double Pip** (600 Hz): DSP Bypass toggled
- **Strictly Isolated Routing:** Chimes are synthesized procedurally in real-time and mixed **exclusively** into your headphone monitor sink. Your friends on Discord and stream listeners on the virtual cable will **never** hear them.

---

### 7. 🎨 Dark-Themed Settings & Hotkeys GUI
- **Dedicated GUI Window:** Launch at any time via tray menu or command line:
  ```bash
  micforge settings
  # or
  micforge hotkeys
  ```
- **Features:**
  - Interactive Hotkey Recorder: click "Record", press your shortcut, and click "Save".
  - Audio Cue Volume Slider: adjust headphone feedback volume (0% to 100%).
  - "Test Chime" button: preview sound cues instantly before saving.
  - Windows Boot Autostart checkbox.
- **Pure Python:** Built with native Tkinter — fast loading with zero heavy browser or Electron dependencies.

---

### 8. 💻 Windows CMD & Terminal Optimizations
- **VT100 & UTF-8 Auto-Configuration:** Automatically sets Windows console code page to 65001 (UTF-8) and enables virtual terminal processing.
- **Stutter-Free Dashboard:** Render rate is throttled to a clean 10 FPS on legacy `cmd.exe` to avoid console buffer saturation and eliminate cursor flickering.

---
