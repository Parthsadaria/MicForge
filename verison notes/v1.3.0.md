## 🎙️ 1. Adaptive Noise Profiling & Environments (`src/micforge/audio/noise_profile.py`)

### The Challenge
Microphone noise calibration used to be a one-time "silent room" ritual. However, room acoustics drift constantly: computer fans ramp up during gaming, air conditioning cycles on and off, and mechanical keyboards generate sharp acoustic transients.

### The Solution
- **Continuous Voice-Aware Learning:** A standalone low-rate background profiler continuously tracks ambient noise changes with strict safety bounds ($\le 1.0$ dB/s maximum drift rate).
- **Strict Safe Adaptation Rules:**
  - *Never learns on speech:* Learning is instantly inhibited whenever voiced frames or speech probabilities ($> 0.25$) are detected.
  - *Transient spike rejection:* Loud energy bursts ($> 16$ dB above current floor, e.g. keyboard clatter or desk bumps) are rejected.
  - *Quiet block requirement:* Adaptation only engages after sustained ambient silence ($\ge 5$ consecutive quiet blocks).
- **Built-in & Custom Environment Profiles:**
  - `quiet_room`: Baseline studio profile (-64 dBFS floor, -52 dBFS gate).
  - `fan_on`: Heavy low-frequency motor rumble attenuation (-52 dBFS floor, low-tilt compensation).
  - `mechanical_keyboard`: High-frequency transient suppression profile (-56 dBFS floor, -38 dBFS gate).
  - *Custom profiles:* Save and switch custom acoustic profiles via CLI or GUI.
- **CLI Commands:**
  ```bash
  micforge profile list
  micforge profile show quiet_room
  micforge profile switch fan_on
  micforge profile relearn
  ```

## 🔌 2. Hot-Plug Detection & Auto-Recovery (`src/micforge/audio/device_watch.py`)

### The Challenge
USB headsets, microphones, and audio interfaces can disconnect due to loose cables, sleep/wake cycles, or OS endpoint switching. In earlier versions, this could silently crash the audio stream or leave the user muted in calls.

### The Solution
- **Background Topology Watcher:** A lightweight daemon thread polls the PortAudio device registry for added, removed, or changed default audio endpoints without freezing or stuttering audio.
- **Bounded Exponential Backoff Recovery:** When an audio stream error or device disconnect is encountered, Micforge automatically schedules up to 5 re-connection attempts with exponential backoff (0.5s, 0.8s, 1.28s...).
- **Safe Bypass Fallback (Never Silently Muted):** If all 5 recovery attempts fail, Micforge automatically engages a safe passthrough bypass mode. Your raw voice continues through to Discord/OBS instead of failing into silence.
- **Structured Event Notifications:** Emits `DeviceWatchEvent` notifications for desktop toasts, log tracking, and live HUD status badges.

## 📦 3. Redacted Diagnostics Export & Plain-English Doctor (`src/micforge/diagnostics.py`)

### The Challenge
Diagnosing user issues required asking users to dig through console logs, check Windows Sound properties, and paste technical stack traces. Users also worried about leaking personal directory paths or webhook tokens in bug reports.

### The Solution
- **One-Click Diagnostic Bundle (.zip):** Available via CLI (`micforge doctor --export`) or the GUI (**📦 Export Diagnostics (.zip)** button in the Routing tab). Produces a portable ZIP archive containing:
  - `diagnostic_report.json` – Complete system, audio backend, and DSP status.
  - `doctor_summary.txt` – Plain-English health status and root-cause hints.
  - `devices.txt` – Complete PortAudio hardware topology.
  - `config_redacted.json` – Active configuration with all sensitive data sanitized.
  - `recent_logs.txt` – Recent operational logs and error traces.
- **Zero-Telemetry Secret Redaction:** Recursively sanitizes API keys, passwords, bearer tokens, URLs with embedded credentials (`https://***:***@...`), and OS home paths (`<USER_HOME>`). No telemetry is ever sent over the network.
- **Plain-English Doctor Assessment:** Evaluates platform health, DSP speed, buffer safety, and sample rate matching with actionable next steps.

## ⏱️ 4. End-to-End Latency Benchmark (`src/micforge/audio/latency.py`)

### The Challenge
Users often ask: *"How much delay is Micforge actually adding to my voice?"* Previous versions only reported theoretical DSP buffer delays, ignoring hardware capture, ring buffer cushions, and DAC render blocks.

### The Solution
- **Loopback Chirp Cross-Correlation:** Sends a 60 ms band-limited logarithmic chirp (800 Hz $\to$ 4000 Hz) with smooth Hanning window edges through hardware loopback. Normalized FFT cross-correlation detects the exact roundtrip peak with sub-millisecond precision and peak-to-sidelobe (PSLR) confidence scoring.
- **Per-Stage Latency Breakdown:**
  - 1. Input Hardware Buffer (e.g. 5.3 ms at 256 samples)
  - 2. 11-Stage DSP & Neural AI Pipeline (~1.5 ms)
  - 3. Ring Buffer Jitter Cushion (~15.0 ms)
  - 4. Output Hardware Buffer (~10.0 ms)
- **CLI Benchmark Tool:**
  ```bash
  micforge latency
  ```
  Reports estimated one-way mouth-to-Discord latency along with tailored hardware tuning advice.

## 🎛️ 5. Simple vs. Advanced Tuning UX (`src/micforge/ui/tuning.py`)

### The Challenge
Casual streamers want 3 or 4 simple controls to adjust their sound without worrying about Q-factors, compression attack curves, or highpass slope rates. Meanwhile, audio engineers need direct access to parametric EQ bands and limiter thresholds.

### The Solution
- **4 Intuitive Macro Knobs (Simple Mode):**
  - **Clarity (0–100):** Adjusts 280 Hz mud cut (-1 to -4.5 dB), 3.2 kHz presence boost (+0 to +6 dB), 9 kHz air shelf (+0 to +5 dB), and automatic de-esser thresholding.
  - **Warmth (0–100):** Adjusts Proximity effect amount, chest resonance body Hz (105–140 Hz), and harmonic warmth.
  - **Noise Removal (0–100):** Scales CoFi-Lite AI neural suppression depth (14–34 dB) and noise gate aggressiveness.
  - **Room Cleanup (0–100):** Adjusts room flutter De-Verb suppression (0–85%) and high-pass rumble filter cutoff (75–110 Hz).
- **Advanced Mode:** Unlocks full parametric EQ bands, de-esser threshold/ratio, compressor attack/release/knee/makeup gain, and limiter ceiling.
- **Immutable Presets:** Built-in factory presets are never overwritten; custom tunings can be saved as user presets or reset to baseline with one click.

## 📖 6. Troubleshooting & FAQ Documentation (`docs/TROUBLESHOOTING.md`)

Added a centralized troubleshooting guide covering the top real-world hurdles:
- **No audio in Discord / OBS:** VB-CABLE and BlackHole setup, recording volume sliders, and OS privacy permissions.
- **Robotic / Underwater voice:** Krisp + Micforge dual-filtering conflict resolution, sample rate mismatch troubleshooting (44.1 kHz vs 48.0 kHz).
- **Echo or game sound bleed:** Far-end AEC reference loopback configuration and room cleanup.
- **High latency:** Buffer size optimization (`--block 128` vs `256`), WASAPI shared vs exclusive modes.
- **Clicks after sleep / wake:** USB selective suspend settings, power management, and clock re-calibration.
